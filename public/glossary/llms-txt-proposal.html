llms.txt Proposal

AI & Agentic Systems • UX & Product Architecture Emerging

Definition

The llms.txt Proposal is a proposed web standard specifying a curated, Markdown-formatted navigation map located at a website's root (/llms.txt), pointing AI models and agents to core content pages.

Purpose

Provides AI agents with a clean, low-token navigation index of high-value site documentation, bypassing the clutter of heavy HTML scripts and complex navigation trees.

Key Concepts

/llms.txt root filecurated link markdownlow-token context aid/llms-full.txt companion.

How It Works

The server hosts a lightweight markdown file with H project names, summary blockquotes, and link lists with 1-line descriptions, accompanied by raw .md content mirrors.

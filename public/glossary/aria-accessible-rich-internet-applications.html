ARIA (Accessible Rich Internet Applications)

Design Systems & Engineering • UX & Product Architecture Established

Definition

WAI-ARIA (Accessible Rich Internet Applications) is a W3C specification providing semantic roles, states, and properties that extend HTML to communicate interactive component behaviors to assistive technologies.

Purpose

Bridges accessibility gaps in complex, dynamic, custom user interface widgets (e.g., tree grids, custom modals, tabs) where native HTML elements do not exist.

Key Concepts

Rolesstatespropertieslive regionsaccessibility tree binding.

How It Works

Developers apply ARIA attributes (e.g., role="dialog", aria-expanded="false") to DOM elements, programmatically mutating their state during runtime user interactions.

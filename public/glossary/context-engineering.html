Context Engineering

AI & Agentic Systems • UX & Product Architecture

Context engineering is the practice of selecting, organizing, and updating the information available to a language model for a task. For an AI agent, that information can include instructions, conversation history, retrieved documents, tool descriptions, and tool results.

What does context engineering involve?

The team decides what the model needs for its next step and how that information should be supplied. This can mean retrieving a relevant policy, keeping the current task state, choosing which tools to expose, or summarizing older messages while preserving facts the task still needs.

Prompt engineering focuses on the instructions and examples given to the model. Context engineering also covers the other information provided during the interaction. Retrieval-augmented generation can supply external content as part of that process.

Example: Explaining a booking change

A traveler asks, “Can I move my flight to Friday?” The assistant needs the selected booking, the intended Friday, and the applicable fare rules. If several dates or bookings are possible, it asks the traveler to clarify.

A tool retrieves current booking data and the relevant rule text. The model receives those results with instructions to explain the conditions and identify anything still unresolved. If the system retrieves a new quote, it also keeps the quote’s time and expiry information in context so the response can identify the price being discussed.

How do you evaluate context quality?

Create representative tasks with expected outcomes. Test whether the assistant selects the right booking and policy, notices missing information, and supports its explanation with the retrieved evidence. Include stale and conflicting results in the evaluation.

Compare changes against the same tasks. Record answer correctness and task completion alongside latency and token use. A shorter context can omit a crucial restriction, and additional context can introduce irrelevant or conflicting material. Compare both versions to find which information the task and model need.

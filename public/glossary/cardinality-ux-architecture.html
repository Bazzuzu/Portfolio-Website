Cardinality (UX Architecture)

UX & Product Architecture • Design Systems & Engineering

Definition

In UX architecture, Cardinality defines the numerical and structural relationships between connected domain objects, specifically classifying whether associations are one-to-one, one-to-many, or many-to-many across user navigation paths.

Purpose

Dictates interface layout structures, container types, pagination behaviors, and relational navigational paths to prevent dead ends and cognitive mismatch.

Key Concepts

One-to-one (1 : 1)one-to-many (1 : N)many-to-many (N : M)directional traversal

How It Works

Designers evaluate entity links during the relationships phase, choosing appropriate navigation controls such as master-detail splits, inline lists, or relational tags.

Related Terms

  • Structural Navigation Model

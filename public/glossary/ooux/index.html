OOUX and ORCA

UX & Product Architecture

Explore the OOUX and ORCA glossary through the questions a product team needs to answer: what people work with, how those things connect, what users can do, and what information they need.

Start with Object-Oriented UX for the design approach and ORCA Framework for the four iterative rounds. Then follow the worked booking example to see how the pieces fit together.

Discover the product's structure

Use Noun Foraging to identify candidate objects from research. Investigate connections with a Nested Object Matrix, actions with a CTA Matrix, and information through Object Mapping.

Object Attributes in OOUX explains core content, metadata, and the distinction between a field and a related object.

Clarify requirements

An Object Guide records what each object means. ORCA Relationship Requirements examines how connections work, while Cardinality clarifies permitted counts in both directions.

Object-Oriented User Stories develops the reason and conditions for an action. A State Transition Matrix can document the lifecycle behind it.

Prioritize the release and the experience

These four activities address related decisions:

Activity Question
Object Prioritization Which things need support, and how will users reach them?
Relationship Prioritization Which connections and navigation paths matter for the task?
CTA Prioritization Which actions need support and prominence in this context?
Attribute Prioritization Which information helps users identify, compare, and act?

Represent and test the model

Object Representation connects the model to cards, lists, and detailed views. A Shapeshifter Matrix helps document intentional variants.

Use the Four UX Fails in OOUX as a diagnostic lens, Content Prototyping to populate the model, and OOUX Prototyping and Testing to observe recognition, navigation, and action understanding.

Work through more complex models

A Junction Object can represent a connection with its own information. Tree Systems describes related forms that become more specific in context. Object Inheritance in OOUX examines general types and meaningful subtypes.

For surrounding practices, explore Content Modeling, Domain Context Modeling, and Structural Navigation Model.

To plan collaborative work, see ORCA Sprint. Choose a bounded problem and use the relevant tools; revisit research whenever the model exposes an unanswered question.

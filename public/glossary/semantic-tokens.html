Semantic Tokens

Design Systems & Engineering • UX & Product Architecture Established

Definition

Semantic Tokens (or Alias Tokens) are contextual design tokens whose names communicate intended UI purpose and intent (e.g., surface-danger-subtle) rather than raw literal values (e.g., red-500).

Purpose

Decouples component implementation from literal brand values, enabling dynamic multi-theme switching, high-contrast modes, and seamless dark-mode re-theming.

Key Concepts

Intentional namingalias referencescontextual abstractiontheme aliasing.

How It Works

A semantic token maps its to an underlying global primitive token alias (e.g., "": "{color.palette.red.500}"), resolving dynamically based on the active theme.

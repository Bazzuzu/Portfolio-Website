Agent Skills (SKILL.md)

AI & Agentic Systems • Design Systems & Engineering Emerging

Definition

Agent Skills are structured file-system directories containing a SKILL.md manifest, procedural instructions, execution scripts, and resource references that supply agents with specialized capabilities on demand.

Purpose

Scales agent capabilities modularly without bloating model prompt windows, loading context dynamically only when specific tasks are triggered.

Key Concepts

File-system-first architectureSKILL.md manifestunbounded contextmodular execution.

How It Works

Agents scan skill catalogs; when a task matches a skill's metadata, the agent loads procedural files and executes localized helper scripts.

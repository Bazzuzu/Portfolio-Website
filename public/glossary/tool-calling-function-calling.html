Tool Calling (Function Calling)

AI & Agentic Systems • Design Systems & Engineering Established

Definition

Tool Calling (or Function Calling) is an API capability where an LLM determines that an external action is needed, outputting a structured JSON object specifying function names and arguments rather than plain text.

Purpose

Empowers probabilistic text models to safely invoke external software functions, query relational databases, and drive computational side effects.

Key Concepts

Function signaturesJSON Schema definitionsprogrammatic executionargument parsing.

How It Works

The host application passes available tool schemas to the model; the model evaluates user intent, returns argument JSON, and pauses until the host returns execution results.
